# macOS 桌面 GUI 自动化控制规范 (Peekaboo)

在 macOS 平台调用 `mcp__desktop__*` 工具或操作桌面软件时，严格执行以下控制契约：

## 1. 观察先行（Observe First 强制契约）
- **唯一合法首发动作**：第一步有且仅能调用 `mcp__desktop__see` 或 `screenshot` 获取当前屏幕画面与无障碍元素标注。
- **状态研判**：确认目标应用确切状态（最前台 Frontmost、Dock 栏带指示灯运行、顶部菜单栏状态项、或完全未运行）。

## 2. 应用唤醒决策阶梯
1. **后台常驻（黄金通道）**：Dock 栏存在图标（带正在运行指示圆点）或屏幕顶部菜单栏状态区（Menu Bar Status Item）存在常驻图标时，**直接单点 Dock 图标或调用原生唤醒 `mcp__desktop__app`**。**严禁对已知常驻应用重复调用启动命令**。
2. **普通最小化**：单点 Dock 栏右侧收纳的最小化窗口缩略图展开。
3. **冷启动（绝对最后）**：Dock 栏与顶部菜单栏均彻底查无应用时，方可启动新进程。

## 3. 语义先行，严禁凭经验盲猜坐标（No Blind Clicking）
- 注入文本前，当前观察界面中**必须确凿存在可编辑控件（`AXTextField` / `AXTextArea` / 编辑区域）**。
- **未见编辑框 = 目标会话/文档根本未打开**，绝对禁止凭借主观经验盲猜绝对坐标点击空白区域！
- **纠偏流转**：优先单点左侧主会话列表条目；若点击后界面弹出了高亮次级菜单/浮层，**必须继续单点该展开项**以进入目标工作区。

## 4. 目标身份强断言
- 提交前必须核实当前活动窗口标题与目标对象 100% 吻合；不匹配立即终止。

## 5. 两阶段提交与剪贴板安全注入
- **阶段一（填充）**：显式单点编辑区域赋予焦点；大段文本、标点或中文**一律使用剪贴板中转后模拟 `command+v` 粘贴**，严禁直接模拟打字绑定回车。
- **阶段二（提交）**：核对活动作用域无误后，再单独下发单次提交动作（单点明确的“发送/确认”按钮或确认聚焦后下发 Return / Enter）。

## 6. 零幻觉核验底线（Zero-Hallucination Gate）
- 提交后再次调用观察工具，必须在界面中**确凿检索到刚刚注入的实体文本内容**。
- 未检索到内容必须直接判定失败并如实向用户报错，**绝对禁止以“界面渲染可能延迟/隐藏”等主观借口虚假宣称成功**。

## 7. 现场清理与复原（Context Restoration）
- 操作后台常驻应用完成后，**必须通过左上角黄色最小化按钮或快捷键 `command+m` 将窗口复原回后台**，保持桌面干净整洁。

## 8. 异常处理
- 遇非预期弹层或菜单，调用快捷键 `esc` 退出重置焦点。
