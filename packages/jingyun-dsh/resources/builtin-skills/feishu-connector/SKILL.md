# 飞书连接器技能 (feishu-connector)

本技能用于在智能体完成分析、会议安排、报表产出或用户要求时，通过已授权的飞书连接器执行消息推送、日程对齐与表格协作。

## 适用场景

1. **工作通知与群消息**：向飞书指定群聊或单聊推送文本通知、进展材料或卡片。
2. **日程管理**：查询某时段团队成员的日程闲忙状态，创建会议日程并邀请参会人。
3. **多维表格（Base）协同**：在已有飞书多维表格中插入、更新或统计任务状态。

## 执行工作流

### 1. 发送飞书消息 / 群通知
直接调用内置脚本：
```bash
python scripts/feishu_tool.py --action send --content "今天 15:00 在 3 楼会议室开周会，请各位准时参加。"
```
> 若需要指定特定群聊或用户，可附加 `--receive-id "oc_xxxx"` 参数。

### 2. 日程与高级协作指令（通过已配置的 lark-cli）
- **查看我的飞书日程**：
  ```bash
  lark-cli calendar event list
  ```
- **创建会议日程**：
  ```bash
  lark-cli calendar event create --summary "【项目规划对齐】" --start-time "2026-09-15T15:00:00+08:00" --end-time "2026-09-15T16:00:00+08:00"
  ```
- **查询飞书群列表**：
  ```bash
  lark-cli im chat list
  ```

## 注意事项

- 执行前请确保客户端连接器面板中飞书显示为已授权状态。
- 如果命令执行提示凭据过期，可引导用户在连接器面板点击“重新授权/登录”。
